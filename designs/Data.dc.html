What the fields mean

blocks[].type
step · heading · note · warning · text · image · table, in the same order as the wiki.
dialogue key
1–9 number key · ✓ accept quest · ~ any option · ? number varies
dialogue when
null for the normal list. Text like “If you finished The Hand in the Sand” for another case.
html
The wiki's own words. Only links, bold and italics are kept.
id
Part id + step number, so your ticks stay put after a refresh.
